# drabuziu-nuoma
Drabužių nuomos sistema finansinių technologijų sprendimų moduliui
#
# start the project

clone repo:
```
git clone https://github.com/gabijux/drabuziu-nuoma.git
cd drabuziu-nuoma
```
install dependencies:
```
npm install
```

start the project:
```
npm run
```

Open http://localhost:5173 in your browser.
